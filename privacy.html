1. 적용 범위

오늘의 수확은 회원가입 없이 이용하는 과일 합성 퍼즐 게임입니다. 앱에는 기본 게임에 필요한 파일이 포함되어 있어 오프라인으로 플레이할 수 있습니다. 외부 지원·정책 페이지를 열거나 다른 서비스로 공유·문의하려면 인터넷 연결이 필요할 수 있습니다.

현재 버전에는 운영자가 관리하는 게임 서버, 계정 서버, 클라우드 저장 서버가 없습니다. 앱은 게임 진행과 개인 기록을 운영자에게 자동 전송하지 않습니다. 기기에 저장하는 게임 기록, 운영체제의 백업, 이용자가 선택하는 공유와 이메일 문의, 웹 페이지 접속은 아래와 같이 각각 처리됩니다.

3. 광고·분석·결제와 기기 접근

iPhone·iPad 앱 0.1.0에는 Kakao AdFit 3.22.7 SDK와 상단 배너 광고 기능이 포함됩니다. 이 방침의 시행일 기준, 이 앱의 광고단위는 등록되지 않았고 공개 광고 설정은 비활성입니다. 이 상태에서 앱 코드는 SDK 배너를 만들거나 광고 요청을 실행하지 않으며, 상단 배너 영역은 빈 공간으로 남습니다. 광고 기능을 활성화할 때에는 실제 정보 처리와 공개 방침·앱 스토어 개인정보 안내를 먼저 확인합니다. 이후 이 앱의 전용 광고단위가 등록되고 유효한 광고 설정과 이용자의 iOS 추적 허용 조건을 모두 충족해야 배너를 요청할 수 있습니다. Android 앱과 웹 데모에는 광고 SDK를 포함하지 않습니다.

추적 허용: 활성 상태의 유효한 광고 설정이 있고 추적 권한을 아직 선택하지 않은 경우 iOS의 앱 추적 투명성(ATT) 권한을 요청합니다. 현재 비활성 설정에서는 이 권한 창을 요청하지 않습니다. 허용하면 SDK가 맞춤형 광고와 광고 효과 측정을 위해 광고 식별자를 사용할 수 있습니다. 거부·제한하거나 아직 선택하지 않은 경우 이 앱은 SDK 광고 요청을 하지 않습니다. 허용하지 않아도 게임 기능과 기록에 제한이 없습니다. 선택은 iOS 설정의 개인정보 보호 및 보안 → 추적에서 변경할 수 있습니다.

공급자는 위 여섯 항목을 사용자와 연결하지 않는 것으로 선언합니다. 이 설명은 포함된 SDK 버전의 선언에 따른 것이며, 현재 광고 비활성 상태에서 위 정보가 모두 전송된다는 의미는 아닙니다. 이 앱은 게임판, 점수, 개인 기록, 이름이나 이메일을 AdFit에 직접 전달하지 않습니다. AdFit은 광고 요청과 응답에 필요한 네트워크 접속 정보를 처리할 수 있습니다. SDK가 처리하는 정보의 보관과 이용자 권리 행사에 관한 사항은 Kakao 개인정보처리방침 및 AdFit 고객센터를 참고해 주세요.

광고 설정 확인: iOS 앱은 실행·전경 복귀 시와 전경 사용 중 약 5분 간격으로 공식 GitHub Pages의 고정된 설정 파일을 HTTPS로 요청합니다. 설정 파일에는 광고 활성화 여부, 대상 앱 버전·식별자, 광고단위 ID, 배너 위치·크기와 유효기간 등의 설정값이 들어갑니다. 앱은 게임 기록이나 개인 식별자를 설정 요청에 넣지 않습니다. 이 설정 확인은 광고가 비활성인 경우와 추적을 허용하지 않은 경우에도 이루어집니다. 파일 제공 과정에서 GitHub에 IP 주소 등 접속 정보가 전달됩니다. GitHub는 GitHub Pages 방문자의 IP 주소를 보안 목적으로 기록·저장한다고 안내합니다. 설정을 가져오지 못하거나 검증에 실패하면 광고를 요청하지 않으며, 오프라인에서도 게임은 계속 이용할 수 있습니다.

별도의 게임 이용 분석 SDK, 개발자 오류 보고 SDK, 인앱 구매와 결제 기능은 없습니다. 광고 활성화 또는 처리 방식 변경 전에 실제 동작에 맞춰 이 방침과 앱 스토어의 개인정보·광고 관련 항목을 확인합니다.

게임은 연락처, 위치, 사진, 카메라, 마이크 또는 전화·문자 내용에 접근하지 않습니다. 점수 문구를 복사하거나 공유하는 기능은 이용자가 선택했을 때만 사용합니다.

4. 운영체제의 백업과 기기 이전

앱 자체에 클라우드 저장 기능이 없어도, 운영체제의 백업이나 기기 이전 기능이 앱 데이터를 보관하거나 옮길 수 있습니다.

Android 앱은 운영체제의 백업을 허용하도록 설정되어 있습니다. Android 버전, 기기 제조사, 계정과 백업 설정에 따라 게임 기록과 설정 등이 백업 또는 기기 이전 대상이 될 수 있습니다. iPhone과 iPad에서도 이용자의 iCloud 백업이나 기기 이전 설정에 따라 앱 데이터가 보관·복원될 수 있습니다.

이 처리는 Google, Apple 또는 기기·백업 서비스 제공자가 이용자 설정과 해당 서비스의 방침에 따라 수행합니다. 운영자는 그 백업 저장소에 직접 접근해 기록을 열람하거나 삭제할 수 없습니다. 모든 기기에서 기록 복원이나 기기간 동기화가 된다고 보장하지 않습니다.

백업 범위와 삭제 방법은 기기 또는 서비스 설정에서 확인할 수 있습니다.

5. 이용자가 선택하는 공유와 복사

공유 화면에는 이용자가 확인할 수 있도록 점수와 플레이 조건을 먼저 표시합니다. 이 문구에는 현재 또는 최종 점수, 합성 횟수, 수박 개수, 게임 모드·판 크기·열매 수, 도전 날짜 등이 포함될 수 있습니다. 현재 출시 버전은 공유 문구에 외부 게임 링크를 포함하지 않으며, 계정 ID나 개인 연락처도 넣지 않습니다.

다른 앱으로 공유: 이용자가 공유를 선택하면 점수와 플레이 조건이 담긴 문구를 운영체제의 공유 기능으로 전달합니다. 이용자가 고른 카카오톡 등 대상 서비스가 전송과 보관을 처리하며, 그 서비스의 개인정보처리방침이 적용됩니다. 오늘의 수확이 연락처를 읽거나 수신자를 골라 자동으로 메시지를 보내지는 않습니다.

점수 문구 복사: 복사 버튼을 누르면 화면의 문구를 기기의 클립보드에 씁니다. 기존 클립보드 내용을 읽어 분석하거나 운영자에게 전송하는 기능은 없습니다. 복사한 내용의 보관과 붙여넣기는 운영체제와 이용자가 선택한 앱의 동작에 따릅니다.

공유와 복사는 선택 사항이며, 이용하지 않아도 게임을 플레이할 수 있습니다. 이미 다른 서비스로 보낸 메시지는 오늘의 수확의 데이터를 지워도 자동 삭제되지 않습니다. 해당 서비스의 삭제 기능을 이용해 주세요.

7. 웹 페이지와 외부 서비스

공식 지원·정책 페이지와 iOS 광고 설정 파일은 GitHub Pages를 통해 제공합니다. GitHub의 정보 처리 안내는 GitHub 개인정보처리방침에서 확인할 수 있습니다.

지원·정책 페이지를 열거나 앱이 광고 설정 파일을 요청하면 콘텐츠를 전달하는 GitHub 등 서비스 제공자에게 IP 주소, 접속 시각, 요청한 페이지 주소, 브라우저 정보 등 페이지 제공과 보안에 필요한 접속 정보가 전달될 수 있습니다.

GitHub는 로그인 여부와 관계없이 GitHub Pages 방문자의 IP 주소를 보안 목적으로 기록·저장한다고 안내합니다. 자세한 내용은 GitHub Pages 개인정보 안내를 참고해 주세요. 운영자는 지원·정책 페이지에 별도의 이용 분석·광고 추적 코드를 넣지 않습니다. 다만 GitHub가 서비스 운영과 보안을 위해 처리하는 접속 정보까지 기기 안에만 머문다는 뜻은 아닙니다. 해당 정보의 보관·삭제는 GitHub의 방침과 설정에 따릅니다.

외부 서비스로 이동한 뒤에는 그 서비스의 정보 처리 방침이 적용됩니다. 이용자가 지원 페이지를 방문하거나 공유·문의하는 선택과 관계없이, 앱 안의 기본 게임은 운영자의 게임 서버에 접속하지 않고 이용할 수 있습니다.

8. 게임 기록 보관·삭제와 정보 보호

게임 기록과 설정은 이용자가 앱·사이트 데이터를 삭제하거나 해당 저장소가 제거될 때까지 기기에 남을 수 있습니다. 저장 공간 부족, 브라우저 설정 또는 운영체제의 저장소 관리로 기록이 사라질 수도 있습니다. 운영자는 기기의 로컬 기록을 별도 서버에 보관하지 않으므로 원격으로 찾아 복원할 수 없습니다.

  • Android: 기기 설정에서 앱 → 오늘의 수확 → 저장공간 → 데이터 삭제 또는 저장공간 삭제를 선택하면 앱의 로컬 기록을 지울 수 있습니다. 메뉴 이름은 기기마다 다를 수 있습니다. 캐시 삭제만으로는 기록이 모두 지워지지 않을 수 있습니다.
  • iPhone·iPad: 설정 → 일반 → iPhone 저장 공간 또는 iPad 저장 공간 → 오늘의 수확 → 앱 삭제를 사용합니다. 앱을 정리하여 문서·데이터를 남기는 기능은 전체 데이터 삭제와 다릅니다.

삭제한 기록은 되돌릴 수 없을 수 있습니다. 운영체제에 남은 백업이나 기기 이전으로 일부 정보가 다시 복원될 수 있으므로, 백업까지 지우려면 Google·Apple 또는 기기 제조사의 백업 설정을 함께 확인해 주세요. 앱에는 회원 계정이 없어 별도의 회원 탈퇴 절차는 없습니다.

게임 기록은 운영체제와 브라우저가 관리하는 저장 영역에서 처리하며, 해당 저장소의 보호 기능을 따릅니다. 운영자는 문의 처리에 필요한 범위로 메일 접근을 제한합니다. 기기 잠금과 운영체제 업데이트도 기기에 남은 기록을 보호하는 데 도움이 됩니다.

광고, 계정 로그인, 클라우드 저장, 온라인 순위표 등 정보 처리 기능을 추가하거나 처리 방식이 달라지면 변경 내용에 맞게 이 방침을 갱신하고 앱과 공개 정책 페이지에서 안내합니다. 특히 앱 업데이트 또는 원격 설정 변경으로 배너 광고를 활성화하기 전에는 광고 사업자·SDK, 처리 정보, 추적·맞춤 광고 여부와 제3자 제공 범위를 최종 구현에 맞춰 다시 검토하고 문구를 수정합니다. 별도 안내나 동의가 필요한 변경에는 그 절차를 적용합니다.
